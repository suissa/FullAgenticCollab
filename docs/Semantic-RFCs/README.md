# FACoP Semantic RFCs

This directory defines the semantic layer of the Full Agentic Collaboration Protocol (FACoP). The FACoP specification states normative protocol requirements; these RFCs define the meaning, identity, relations, invariants and proof obligations of its concepts.

## Status

The collection is experimental and aligned with FACoP v0.2. Semantic RFCs MUST NOT silently change the normative protocol. A change to an invariant, identity rule or lifecycle meaning requires a FACoP version decision.

- RFC-0002 — FACoP semantic model

- RFC-0004 — ProblemProof and SolutionProof
- RFC-0005 — Evidence, EvidenceKey and EvidencePassport
- RFC-0006 — Lifecycle states and transitions
- RFC-0007 — Contributor and Upstream planes
- RFC-0008 — Independent regeneration
- RFC-0009 — Trust, authority and security boundaries
- RFC-0010 — FACoP events and interoperability
- RFC-0011 — Provenance without chain-of-thought
- RFC-0012 — Acceptance, qualification and promotion

## Common rule

Each RFC defines terms, relations, invariants, forbidden interpretations, examples and proof obligations. Machine-readable schemas and executable tests are the final validation surface for claims that can be automated.
